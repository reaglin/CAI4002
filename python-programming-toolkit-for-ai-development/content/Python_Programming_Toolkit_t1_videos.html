Introduction

Before you can write a single line of AI code, your machine needs a working, predictable Python setup. This topic walks through installing Python 3, confirming the installation actually works from your terminal, and then isolating each project in its own virtual environment so that the libraries you install for this course never collide with other projects or with your operating system's Python.

This matters more in an AI course than it might seem. The libraries you will use later in this module - NumPy, pandas, scikit-learn - are version-sensitive, and code that runs on your laptop should also run on a grader's machine or a classmate's. Virtual environments plus a pinned requirements file are what make that possible, and knowing how pip and conda differ will save you hours when an install fails.

As you watch the videos, pay attention to the exact commands being typed and to where files end up on disk. Notice how the shell prompt changes when an environment is activated, how a package is installed into that environment rather than globally, and how the speaker diagnoses problems such as a command not being found or the wrong Python version answering. Those small observations are the ones you will reuse whenever setup goes wrong.

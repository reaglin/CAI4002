Introduction

AI algorithms are usually first described as pseudocode: expand a node, push it onto a frontier, mark a state visited, recurse into a child. Turning that pseudocode into working Python is mostly a matter of knowing a handful of core language constructs well. This topic reviews those constructs — functions, classes, comprehensions, generators, recursion, exception handling, and type hints — and focuses on using them so that your code reads almost like the pseudocode it came from.

Each construct maps onto something you will do repeatedly in this course. Functions package a single algorithmic step so it can be tested and reused; classes model the things in a problem (a Node, a State, an Agent, an Environment); comprehensions express "build the list of successors" in one readable line; generators let you produce candidate states lazily instead of materializing an enormous list; recursion mirrors the structure of trees and graphs; exceptions keep an algorithm from crashing on bad input; and type hints document what a function expects so your code survives being read a week later.

The three videos below cover functions, generators, and class-writing with dataclasses. While watching, pay attention to the mechanics (parameters, return values, yield, field defaults) but also to the design question behind each one: what belongs in a function versus a class, and when is producing values one at a time better than returning a full list? Try re-implementing each example in your own environment rather than only watching.

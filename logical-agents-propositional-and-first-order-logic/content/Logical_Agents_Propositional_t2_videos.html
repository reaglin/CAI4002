Introduction

Propositional logic is the simplest formal language that a knowledge-based agent can use to represent what it believes about the world. Its syntax tells you which strings of symbols count as sentences: atomic propositional symbols such as P or Rain, combined with the connectives for negation, conjunction, disjunction, implication, and biconditional, assembled according to a formal grammar (often written in BNF). Its semantics tells you what those sentences mean: a model is simply an assignment of true or false to every propositional symbol, and truth tables define how the truth value of a complex sentence is computed recursively from the truth values of its parts.

This topic matters because everything later in the module depends on it. Entailment, model checking, conversion to conjunctive normal form, and resolution are all defined in terms of the syntax and semantics introduced here, and first-order logic extends this same machinery with predicates, functions, and quantifiers. The key definitions to internalize are validity (true in every model), satisfiability (true in at least one model), and logical equivalence (the same truth value in every model).

While watching, keep two questions separate in your mind: is this string a well-formed sentence (syntax), and in which models is it true (semantics)? Pay particular attention to the truth table for implication, which surprises most students, and to how a truth table enumerates 2^n rows for n propositional symbols — a fact that will matter when we discuss the cost of model checking.

How These Videos Support the Learning Outcomes

Together these three videos target MO2 most directly: the Stanford segment supplies the syntax and formation rules behind well-formed propositional sentences, while the Spanning Tree and Mathispower4u videos establish the standard connectives and their meanings. By grounding every connective in truth tables over all possible truth assignments, they also build the semantic foundation that MO3 requires, since model checking for entailment is nothing more than systematic truth-table enumeration. The notions of validity, satisfiability, and logical equivalence introduced here carry forward into the knowledge-base architecture of MO1 and the richer language of first-order logic in MO4.

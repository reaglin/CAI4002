Introduction

Logic gives us a precise way to say what an agent knows and what follows from that knowledge. The central idea is entailment: a knowledge base KB entails a sentence alpha (written KB |= alpha) when alpha is true in every model — every assignment of truth values to the symbols — in which KB is true. Entailment is a relation about meaning, not about symbol manipulation, and it is the standard against which we judge any inference procedure.

Around entailment sit several related notions. A sentence is valid if it is true in every model, and the deduction theorem links entailment to validity: KB |= alpha exactly when the implication KB => alpha is valid. A sentence is satisfiable if it is true in at least one model, and this gives us proof by refutation: KB |= alpha exactly when KB AND NOT alpha is unsatisfiable, which is precisely how resolution proofs work. Two sentences are logically equivalent when each entails the other, which justifies the rewriting steps used to convert sentences to conjunctive normal form. Finally, an inference procedure is sound if everything it derives is entailed, and complete if it can derive everything that is entailed.

The videos below come from Stanford's CS221 logic unit. As you watch, keep asking two questions: what does this inference rule let me derive, and is it sound and complete with respect to entailment? Pay particular attention to the moment where resolution turns a question about entailment into a question about satisfiability by negating the query — that move is the practical heart of this topic.

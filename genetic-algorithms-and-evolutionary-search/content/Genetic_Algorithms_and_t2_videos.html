Introduction

Before a genetic algorithm can search for anything, you have to decide how a candidate solution will be written down. That written form — the chromosome — is the representation or encoding, and it determines what the search space actually looks like to the algorithm. A bit string, a vector of integers, a vector of real numbers, a permutation of items, or a tree of expressions are all common choices, and each one makes some solutions easy to express and others awkward or impossible.

Representation matters in this course because it constrains everything that follows. Standard one-point crossover and bit-flip mutation work fine on binary strings, but applied to a route through cities they produce nonsense — repeated cities, missing cities — so permutation problems need order-aware operators such as order crossover or swap and inversion mutation. Similarly, real-valued vectors invite arithmetic operators like blend crossover and Gaussian mutation, while tree encodings need subtree exchange. Constraint handling is also tied to encoding: some constraints can be made unbreakable by choosing a representation that cannot express an invalid solution, while others must be handled with penalties or repair.

The videos below use the Travelling Salesman Problem as a running example, which is the cleanest illustration of permutation representation available. While watching, ask yourself: what exactly is one chromosome here, how long is it, what values can each position take, and which operators could be applied without breaking validity? Also notice the contrast between the exact dynamic programming treatment of TSP and the evolutionary treatment — the same problem, but very different assumptions about how the solution space is explored.

How These Videos Support the Learning Outcomes

These videos support MO2 most directly: all three centre on route and path problems, which demand a permutation chromosome rather than a binary or real-valued one, letting you see how problem structure drives the encoding choice and which operators remain legal. The genetic algorithm demonstrations also reinforce MO1 by showing the generational cycle of evaluation, selection, crossover and mutation in context, and touch MO3 because tour length provides a naturally graded fitness signal with validity constraints built into the encoding itself. The dynamic programming treatment supplies the contrast needed for MO5, clarifying why a combinatorial problem of realistic size is tackled with repeated stochastic runs rather than an exact search.

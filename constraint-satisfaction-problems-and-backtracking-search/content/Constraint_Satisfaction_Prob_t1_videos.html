Introduction

A constraint satisfaction problem, or CSP, is a way of describing a problem not by the steps you take to solve it but by the conditions a solution must satisfy. Formally a CSP is a triple: a set of variables, a domain of possible values for each variable, and a set of constraints that restrict which combinations of values are allowed. A solution is an assignment that is both complete (every variable has a value) and consistent (no constraint is violated); along the way a solver works with partial assignments that may be consistent so far but are not yet solutions.

This matters in the course because CSPs are our first example of a problem representation that exposes structure. In general state-space search, states are opaque black boxes and the only thing you can do is generate successors. In a CSP, the state is a set of variable assignments, so a solver can see which variables are still unassigned, how large their remaining domains are, and which constraints are already violated. That visibility is exactly what makes backtracking search, constraint propagation, and the ordering heuristics later in this module possible.

While watching, try to pin down four things in each example: what the variables are, what each variable's domain is, how the constraints are written, and whether a given assignment is partial, complete, consistent, or an actual solution. Also pay attention to how domain type matters — finite and discrete domains (colors, digits, board columns) behave very differently from infinite or continuous ones, and the choice of variables and domains is itself a modeling decision that can make a problem easy or hard.

A short animated explainer that uses the 4-Queens puzzle — a scaled-down Eight Queens problem — to introduce constraint satisfaction. Based on its description, it walks through the puzzle and shows how it can be cast in CSP terms, with variables for the queens and constraints forbidding shared rows, columns, and diagonals. Its brevity makes it a good concrete anchor after the more abstract definitions.

Why this video

It grounds the formalism in a single small example you can follow end to end, which is exactly the kind of modeling practice (choosing variables and finite domains) that the module asks you to do for N-Queens and similar problems.

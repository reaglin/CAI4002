Introduction

Once you have met the main uninformed search strategies individually, the next step is to put them side by side and judge them with a common set of standards. The four criteria used throughout this course are completeness (will the strategy find a solution if one exists?), optimality (will it find the cheapest solution?), time complexity (how many nodes does it generate?), and space complexity (how many nodes must it hold in memory at once?). The comparison relies on a compact notation — b for the branching factor, d for the depth of the shallowest solution, m for the maximum depth of the search tree, and l for a depth limit — so getting comfortable with these symbols is the first task.

The comparison table that results is one of the most useful summaries in classical AI. Breadth-first and uniform-cost search give strong guarantees but pay for them in memory, typically O(b^d). Depth-first search is frugal with memory, O(bm), but is neither complete on infinite or looping spaces nor optimal. Depth-limited search tames depth-first search with a cutoff but can miss solutions deeper than the limit, and iterative deepening recovers breadth-first guarantees at depth-first memory cost by repeating shallow work. Bidirectional search can slash the effective exponent, but only when the problem permits searching backward from an explicit goal.

The two videos below focus on the pair you need to understand most firmly before the rest of the table makes sense: breadth-first and depth-first search. While watching, pay attention to the order in which nodes are expanded, which data structure drives each strategy (queue versus stack), and how many nodes are being held in memory at any moment. Those observations are exactly what the completeness, optimality, time, and space columns are measuring.

How These Videos Support the Learning Outcomes

These videos build the foundation needed for the module's outcomes rather than covering every strategy directly. Understanding how depth-first search expands a branch to its end supports MO1, since depth-limited search is simply depth-first search with a cutoff, and understanding the breadth-first expansion order supports MO2 and MO3, because iterative deepening reproduces breadth-first order through repeated depth-limited passes. Seeing how a frontier grows and shrinks in each strategy also prepares you to reason about frontier intersection in bidirectional search (MO4). Most directly, the explicit BFS-versus-DFS comparison models the kind of criteria-based reasoning required by MO5; you should supplement it with the course materials on depth-limited, iterative deepening, and bidirectional search to complete the full comparison table.
